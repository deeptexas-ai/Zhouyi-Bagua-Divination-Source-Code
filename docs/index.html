Code map

Browser JavaScript with calendar and chart modules

The public tree is not a Docker or Python project. Its verifiable core is JavaScript, plus UI flows that call matching API endpoints.

Calendar

`lunar.js`, `nongli.js` and `paipan.js` handle dates, solar terms and astronomical calendar calculations.

Relationships

`paipan.gx.js` covers Ten Gods, hidden stems and stem/branch clash or combination rules.

Shen Sha

`shensha.js` contains rule tables, descriptions and lookup functions for chart positions.

Application

`index.js` connects inputs, chart rendering, Five Elements views and API-dependent Ziwei flows.
