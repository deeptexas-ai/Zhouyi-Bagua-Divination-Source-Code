代码结构

浏览器 JavaScript、历法与排盘模块

这个公开目录不是 Docker 或 Python 项目。可核实核心是 JavaScript，以及调用配套 API 的产品流程。

历法

`lunar.js`、`nongli.js`、`paipan.js` 处理日期、节气与天文历法计算。

关系

`paipan.gx.js` 处理十神、藏干以及天干地支的刑冲合害。

神煞

`shensha.js` 包含规则表、文字说明和按盘面位置查询的函数。

应用

`index.js` 连接输入、图表、五行界面和依赖 API 的紫微运势流程。
