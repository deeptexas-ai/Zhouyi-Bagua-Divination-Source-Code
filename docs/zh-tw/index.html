程式碼結構

瀏覽器 JavaScript、曆法與排盤模組

這個公開目錄不是 Docker 或 Python 專案。可核實核心是 JavaScript，以及呼叫配套 API 的產品流程。

曆法

`lunar.js`、`nongli.js`、`paipan.js` 處理日期、節氣與天文曆法計算。

關係

`paipan.gx.js` 處理十神、藏干以及天干地支的刑沖合害。

神煞

`shensha.js` 包含規則表、文字說明和按盤面位置查詢的函式。

應用

`index.js` 連接輸入、圖表、五行介面和依賴 API 的紫微運勢流程。
